🚀 Overview

GEAR (Geospatial Educational Augmented Reality) is a Moodle activity module that bridges the gap between traditional e-learning and immersive 3D technology. It allows educators to upload, manage, and present 3D models in an interactive spatial environment.

✨ Core Features

🎮 3D Viewer & Interaction

Smooth orbital controls and high-performance glTF/GLB rendering.

📍 Interactive Hotspots

Multimedia annotations (Text, Audio, Video, Teleport) placed on 3D geometry.

🧪 Spatial Quizzes

Embed assessment points in 3D. Results are automatically synced with the Moodle Gradebook.

✨ AI Assistant & 🗣️ Auto TTS

Generate hotspot descriptions and quizzes using AI, and use built-in Text-to-Speech narration.

👥 Collaborative Mode & 🎙️ WebRTC Voice

Real-time multi-user sessions with 3D avatars and P2P spatial voice and text chat.

📋 Requirements

  • Moodle: 4.5 LTS to 5.3+
  • PHP: 8.2+
  • Browser: Modern browser with WebGL support (Chrome, Edge, Firefox, Safari)
  • Privacy: Implements Moodle Privacy API

🛠 How it Works

  1. Upload: Drag and drop your .GLB or .GLTF models.
  2. Annotate: Use the scene editor to place hotspots and assessment points.
  3. Engage: Students explore, collaborate, and complete integrated activities.
